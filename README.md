# Quản lý sách

Bài giữa kỳ môn Điện toán đám mây.

**Sinh viên:** Dương Bảo Đạt — **MSSV:** 23IT046.

## Chức năng

- Xem danh sách và tìm kiếm sách.
- Đăng nhập, thêm sách và đăng xuất.
- Mã sách bắt đầu bằng `046`; VAT áp dụng `12%`.
- Hiển thị giá trước thuế và sau thuế.

## Công nghệ

Node.js, Express, Handlebars và MongoDB Atlas.

Database: `DB_23IT046`. Kết nối Đọc/Ghi dùng hai tài khoản riêng; session được lưu trên Atlas.
